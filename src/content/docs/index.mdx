## Six models, one stack

Ask any modern coding model to scaffold a React app with no further direction and
the answers converge: a React metaframework, Tailwind for styling, shadcn/ui for
components, TanStack Query for data. The framework column wobbles. The styling and
component columns barely move.

This site turns that observation into something you can **explore** — model by model,
version by version, dimension by dimension.
